Cloud Backend & Database Architecture Guide

Executive Guidance: Do you need a dedicated backend server like Firebase or Supabase right now? Below is the strategic evaluation for Odiins based on current phase and future scaling.

🔥 Firebase Firestore ✓ Connected & Live

Serverless NoSQL Real-Time Cloud Database by Google Cloud Platform.

  • Project ID: odiins-global-services
  • Database: Cloud Firestore (default)
  • Region: asia-south1 (Mumbai)
  • Collection: leads (Dual-write active)
  • Live Sync: Forms ➔ Google Sheets + Firestore
✓ Cloud Firestore Live • Dual-Write Active
📊 Google Sheets Webhook Currently Active

Serverless REST Webhook syncing leads directly to your cloud spreadsheet.

  • Already Live: Connected to your Google Apps Script webhook.
  • Zero Cost: 100% free with your existing Google Workspace account.
  • Collaborative: Team can view, comment, and export rows in Google Sheets instantly.
  • Ideal for Phase 1: Perfectly handles lead intake without server overhead.
✓ Connected & Firing on all 14 pages
⚡ Supabase (Postgres) Best for Job Portal

Open-source relational PostgreSQL backend with Auth and Row Level Security.

  • Relational SQL: Best if Odiins builds candidate user accounts, resume uploads, and employer job boards.
  • Free Tier: 500MB PostgreSQL database and 50,000 monthly active users.
  • Built-in Auth: OTP, Magic Link, and Google sign-in out of the box.
  • When to adopt: Upgrade to Supabase when transitioning into a full SaaS job portal.
🐘 Hostinger MySQL Hosting Included

Traditional MySQL database hosted on your existing Hostinger cPanel.

  • Included Free: Available on your current Hostinger hosting plan.
  • Self-Contained: All data resides on your hosting server.
  • Requires PHP backend: Requires maintaining custom PHP scripts (`api/leads.php`).
  • No native WebSockets: Lacks real-time push updates unless polled.
